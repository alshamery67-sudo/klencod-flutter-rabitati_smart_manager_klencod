متجري الذكي — مشروع أولي لـ Klencod IDE
========================================

محتويات ZIP:
- index.html: واجهة عربية RTL متجاوبة لإدارة المنتجات الرقمية.
- README.txt: هذا الملف.

طريقة الاستخدام:
1. افتح Klencod IDE.
2. اختر "استيراد مشروع من ZIP".
3. اختر ملف rabitati_smart_manager_klencod.zip.
4. بعد الاستيراد افتح index.html أو شغّل معاينة المشروع حسب خيارات التطبيق.

تنبيه مهم:
هذه نسخة واجهة أولية تحفظ المنتجات في localStorage داخل المتصفح/المعاينة.
ليست مرتبطة بعد بقاعدة بيانات SQLite أو Zite أو Whacka، ولا تنفذ الدفع أو النشر الحقيقي.
لا تضع مفاتيح API أو كلمات مرور داخل ملفات الواجهة.
يجب ربطها بخادم آمن قبل استخدامها لإدارة المتجر الحقيقي.
لا تستوردها فوق مشروع قائم أو تستبدل بها قاعدة بياناتك الحالية.
